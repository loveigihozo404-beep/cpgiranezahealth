Backend integration lives in Supabase. The database schema is in `schema.sql` and environment settings are documented in `../.env.example`.

This folder contains the backend data model and Supabase integration contract. The browser application lives in `../frontend/src`.

The requested health data table is defined in `schema.sql` for Supabase and in `mysql.sql` for a local XAMPP MySQL database named `giranezahealth`.
